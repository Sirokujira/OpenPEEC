# OpenPEEC

A quasi-static to full-wave PEEC (Partial Element Equivalent Circuit)
electric-circuit solver in C. Companion project to
[OpenFDTD](https://github.com/Sirokujira/OpenFDTD) — same build conventions,
same portability rules, no external numerical libraries.

準静的〜フルウェーブ PEEC (部分要素等価回路法) による電気回路解析ソルバー (C 言語)。
[OpenFDTD](https://github.com/Sirokujira/OpenFDTD) の姉妹プロジェクトで、
ビルド規約・移植性規則を共有します。外部数値ライブラリ (LAPACK/BLAS/HDF5)
には依存しません。

## Theory / 理論概要

- **MNA (修正節点解析)** : 集中定数素子 R / L / C / 相互インダクタンス K /
  伝送線路 T / 独立電源 (AC) をスタンプした複素連立一次方程式を、周波数ごとに
  自前の複素 LU 分解 (部分ピボット) で解きます。
- **伝送線路 (`tline`)** : 特性インピーダンス Z0・片道遅延 td の TEM 線路
  (SPICE の T 素子に相当) を 2 つの端子対の間に置きます。端子対ごとの
  入射波 a = (v + Z0 i)/2 と反射波 b = (v − Z0 i)/2 が b1 = T a2、b2 = T a1
  (T = a e^{−jω td}) で結ばれる進行波の形 (Branin) で MNA に組むので、
  Z / Y 行列の形と違って ω td = nπ でも特異になりません。省略可能な損失 [dB]
  は無ひずみ線路 (Heaviside、R/L = G/C) の片道減衰 a = 10^(−dB/20) で、
  Z0 は実数のまま周波数に依りません。給電線・整合スタブ・ケーブルを PEEC
  構造と同じ回路に入れられます (線路自体は幾何を持たず、場とは結合しません)。
  単位長さあたりの定数で書く `tline = n1 n2 n3 n4 rlgc 長さ R L G C [Rs [tanδ]]`
  は表皮効果 R(f) = R + Rs√f と誘電損 G(f) = G + ωC tanδ を持つ一般の損失線路で、
  Z0 = √((R+jωL)/(G+jωC)) と γ = √((R+jωL)(G+jωC)) が周波数ごとに複素数になります
  (進行波の形は複素 Z0・T = e^{−γ·長さ} でもそのまま厳密)。
- **部分インダクタンス (L)** : 直線導体 (`wire` / `bar` キー) を区間分割し、
  幾何二重積分 `I = ∬ dl₁dl₂/R` から `Lp = (μ0/4π)(t̂₁·t̂₂) I` を求めて
  区間枝電流を MNA に組み込みます。ポートは 1 A 電流源励振で Zin(f) を
  計算します。
  - 自己項・平行/同一直線の相互項は解析式、一般配置は 8 点
    Gauss–Legendre の複合則 (近接時は 4×4 分割、遠方は中点近似)。
  - 細線縮約カーネル `R = √(|Δr|² + a²)` を全項で統一しているため、
    **直線導体の合計インダクタンスは分割数に依存しません**
    (`Σᵢⱼ Iᵢⱼ = I_self(全長)` が厳密に成立)。
- **導体形状** : 3 種類に対応します。
  - `wire` : 丸線 (半径 a) — 細線フィラメントとして扱う。末尾に `断面分割数 n`
    を書くと、断面を n × n の正方格子のうち中心が円内のセル (矩形バーの
    体積セル。格子間隔は残ったセルの総面積が πa² になるよう伸縮する等面積の
    階段近似) の並列に分割し、表皮効果と近接効果 (隣の導体・地板の鏡像による
    断面内の電流の偏り) を Lp が解きます。DC 抵抗 l/(σπa²) は厳密で、内部
    インダクタンス μ0l/8π も出ます。収束は O(セル幅) (階段の縁) で、
    n = 10 (80 セル) なら表皮・近接による抵抗の増分が −2〜3% 程度です
  - `bar` : 角線 (幅 w × 厚さ t) — 等価半径で扱う。インダクタンスは
    幾何平均距離 `a_L = 0.2235(w+t)` (Grover の角線式を再現)、容量は
    薄板↔丸線の等価 `a_P = (w+t)/4`、抵抗は断面積 `R = l/(σwt)`。
    末尾に `分割数w [分割数t]` を書くと断面を nw × nt の体積セル
    (Hoer–Love の矩形バー) の並列に分割し、断面内の電流の再配分
    (表皮効果・近接効果) を Lp が解きます。分割したセルは長さ方向の各区間の
    両端ノードを共有します (plate の層と同じ VFI 近似)。幅方向は ẑ × 軸
    (水平。軸が z と平行なら x)、厚み方向は 軸 × 幅 = 基板上の配線の向きです。
  - `helix` : らせん / 円形ループ — 丸線の折れ線 (`wire` 列) に展開する
    生成子で、幾何段以降は `wire` と区別しません。コイルや円形ループを
    1 行で書くためのものです。
  - `plate` : 平面矩形の面導体 — 格子に分割し、隣接ノード間を幅をもつ
    面セル (リボン)、各ノードの双対矩形を電荷セルとする標準的な面 PEEC。
    電流は面内 2 方向に流れます。`分割数t` (省略時 1) を 2 以上にすると
    厚み方向にも分割し、セルを体積バーとして扱います (下記)。
- **パネル (`quad` / `disk`) — 非矩形・曲線境界の面導体** : 構造格子で
  分割する平面パネル。`quad` は凸な一般四辺形 (双一次写像の格子)、`disk`
  は円板 (中心 + リング × セクタの極格子)。セルは plate と同じ双対構成の
  一般化 (枝の帯セル + 格子点の双対多角形の電荷セル) で、一般四辺形に
  なるため、一様な平面多角形のポテンシャル閉形式 (辺ごとの和、
  Wilton et al. 1984) を内側解析・外側三角形 Gauss で組み合わせて評価
  します。規格化は `w̄ = 面積/長さ` として `Î = (1/(w̄₁w̄₂))∬∬dS dS′/R`
  (面セルの規格化の一般化。`len·w̄ = 面積` なので P の式も共通)。
  曲面 (円筒など) は平面パネルの集合 (ファセット) で近似します。
- **体積セル (厚み方向の電流分布)** : `plate` の `分割数t` ≥ 2 で有効。
  各層は同じ格子ノードを共有し (各格子点で並列接続)、層のスタックは
  元の平面を中心に対称に置きます。セル間の結合は Hoer–Love の平行矩形バー
  相互インダクタンス閉形式 (J. Res. NBS 69C, 1965) で厳密に評価するため、
  自己項・隣接項・層間相互が整合し、体積を分割した部分和が全体に一致します
  (加法性)。厚み方向の電流再配分 (表皮効果) は Lp 行列が陽に解くので、
  体積セルには `skineffect` の合成式を適用しません (二重計上防止)。
  DC 抵抗は層数に厳密に依存しません。
- **面セルの積分** : 幅で規格化した `Î = (1/w₁w₂)∬∬dS dS′/R` を使うことで、
  `Lp = (μ0/4π)(t̂₁·t̂₂)Î`, `P = Î/(4πε0 L₁L₂)` と細線とまったく同じ式に
  なります (w→0 で細線の式に一致)。内側の面積分は矩形の閉形式で厳密に
  評価するため、自己項・隣接項も安定です。
- **電位係数 (P) / 容量性 PEEC** — `capacitance = 1` で有効:
  容量セルを幾何ノードに割り当て (各区間の半分ずつを両端ノードが持つ)、
  同じ幾何二重積分から `P = I/(4πε0 L₁L₂)` を作り、節点容量行列
  `C = P⁻¹` を MNA の節点ブロックに `jωC` として加えます。
  対無限遠の総容量 `ΣᵢⱼCᵢⱼ` をログに出力します。
  `compression = 1` のときは逆行列を作らず、電荷を陽な未知数にした
  等価な定式化 (`Pq − v = 0`, KCL に `+jωq`) を使います。
- **表皮効果 (R(f) + 内部 L)** — `skineffect = 1` で有効:
  丸線は内部インピーダンス `Z_int = k/(2πaσ)·I₀(ka)/I₁(ka)`
  (`k = (1+j)/δ`, `δ = √(2/ωμ0σ)`) を各区間に適用します。
  `I₀/I₁` は `|ka| < 15` で級数、以上で漸近展開。
  低周波では `R_dc + jωμ0l/(8π)`、高周波では `R = X = l/(2πaδσ)` に
  漸近します。角線は閉形式が無いため、両極限 (`R_dc` と周長 P の表皮層
  `l/(σδP)`) が厳密になる合成式で近似します。
- **遅延 (フルウェーブ PEEC)** — `retardation = 1` で有効:
  カーネルを `e^{-jkR}/R` に置き換え、L と P を周波数依存の複素行列として
  毎周波数で組み直します。特異性抽出
  `∬e^{-jkR}/R = ∬1/R + ∬(e^{-jkR}−1)/R` により、解析式を保ったまま
  第 2 項 (R→0 で −jk に収束する正則関数) だけを求積します。
  これにより放射抵抗が正しく得られます (半波長ダイポールで Rin ≈ 73 Ω)。

  遅延を使う場合、**構造ノードを接地してはいけません**。容量の電位基準は
  無限遠であり、実ノードを接地するとそこから無限遠へ電荷が逃げて構造の
  総電荷が保存せず、放射抵抗の打ち消しが壊れて Rin が負になります。
  `capacitance = 1` のときは基準ノードを常にノード 0 (= 無限遠) とし、
  ノード 0 が未使用ならどの実ノードも消去しません (容量が電位を確定させる)。
  **例外は地板 (`groundplane`) があるとき**で、鏡像が総電荷の保存を自動で
  満たすため、ノード 0 (= 地板電位) にポートを繋いでかまいません
  (モノポール給電はまさにこの形です)。
- **無限 PEC 地板 (鏡像法)** — `groundplane = z0` (z = z0 の面) または
  `groundplane = x|y|z 座標` で有効 :
  軸に垂直な無限完全導体面を鏡像法で扱います。部分インダクタンスは
  幾何鏡像セルとの相互項を鏡像電流の向き (面に平行な成分反転・垂直成分保存)
  込みで減算し、電位係数は鏡像電荷 −q の相互項を減算します。未知数は
  増えません。遅延 (`retardation = 1`) でも同じ経路で有効です。導体は
  すべて地板の + 側 (x_a ≥ 地板) に置きます。λ/4 モノポールの
  Zin = 半波長ダイポール/2 が離散化レベルで厳密に再現されます
  (検証で実測 3e-10)。
  **互いに直交する面を 3 枚まで** (行を重ねて書く。コーナー反射器・箱の隅) :
  面の部分集合ごとに鏡像が 1 つ (2 面で 3 個、3 面で 7 個) あり、電流・電荷は
  反射の回数 n に対して (−1)ⁿ 倍です (直交面の反射は可換なので有限個で厳密)。
  遠方界は導体側の領域 (z 面があれば上半球、x / y 面は面の手前) だけを積分し、
  平面波は入射波ごとに反射波 2^面数 − 1 個を加えます。平行な 2 面 (同じ軸) は
  鏡像が無限級数になるので受け付けません。
- **区分線形の電流基底 (高次基底)** — `basis = 1` (細線のみ、`capacitance = 1` 必須) :
  区間ごとに一定の電流に、節点の電荷 q_n で駆動する傾斜関数
  jω q_n (L_h − s)/L_n を足し、電流を連続な区分線形 (節点と区間中点で折れる) に
  します。試験関数も同じ (Galerkin) なので Z 行列は対称のままで、節点電位は
  節点での点電位になります。平面波の右辺と遠方界の放射ベクトルにも同じ傾斜関数を
  入れるので、送受の相反も保たれます。粗い格子で正確で、半波長ダイポールの
  Rin 誤差は片腕 4 分割で従来の 1/3、8 分割で 1/2 です。ただし電荷が区分一定の
  ままなので、細かい格子では従来の基底 (2 次収束) の方が速く収束します。
  面導体・体積セル・誘電体・`compression`・`nearfield` とは併用できません。
- **励振の重み (アレイ給電)** — `excitation = ポート番号 振幅[A] [位相deg]`
  (複数行可) : 遠方界・近傍界を、ポート j の解 (1 A、他は開放) を重み
  w_j = 振幅·e^{j位相} で重ね合わせた電流・電荷で評価します。線形性から
  これは全ポートに電流 w_j を同時に注入した解そのもの (近似なし) で、
  入力電力は相互結合を含む Pin = ½Re(wᴴZw)。行を書かないポートは開放
  (電流 0) です。書かなければ従来どおり port #1 に 1 A (出力はビット一致)。
- **遠方界の後処理** — `farfield = 分割数θ 分割数φ` で有効 :
  port #1 を 1 A で励振したときの区間電流 (`excitation` を書けば全ポートの
  重み付き励振、下記) から放射ベクトル
  `N = Σ I len t̂ sinc(k len (r̂·t̂)/2) e^{jk r̂·rc}` を求め、`far.csv` に
  r·E の θ/φ 成分・指向性 D・利得 G (dBi) を出力します。放射電力 Prad は
  球面 (地板ありは鏡像込みで上半球) のグリッド積分、放射効率 = Prad/Pin
  (Pin = Re Zin/2、`excitation` があれば相互結合込みの Re(wᴴZw)/2) を
  `peec.log` に出します。効率が意味を持つのは
  `retardation = 1` のときです (準静的電流は放射を含まないため)。
  `planewave` と併用すると、平面波が誘起した電流を放射源にした**散乱界**も
  同じ式で求め、`farpw.csv` に r·E_s の θ/φ 成分と双方向レーダー断面積
  σ = 4π|r·E_s|²/|E₀|² [m², dBsm] を出します。`peec.log` には全散乱断面積
  σ_s = ∮|r·E_s|²dΩ/|E₀|² と、前方散乱振幅から光学定理で求めた消光断面積
  σ_e = −(4π/k) Im[ê·r·E_s(前方)/E₀]、吸収断面積 σ_a = σ_e − σ_s を出します
  (σ_e は地板なしのときのみ。エネルギー保存 σ_e = σ_s + σ_a が成り立つのは
  `retardation = 1` のとき)。
- **近傍界の後処理** — `nearfield = x1 y1 z1 x2 y2 z2 n1 n2 n3` で有効
  (複数行可) : 角 `(x1,y1,z1)` から角 `(x2,y2,z2)` までを各軸 n 分割した
  格子点 (n = 0 の軸は固定) で E と H を求め、`near.csv` に出します。
  port #1 の 1 A 励振 (または `excitation` の重み付き励振) に対する区間電流と
  (`capacitance = 1` なら) セル電荷から
  遅延ポテンシャル `A`・`φ` を積分し、`E = −jωA − ∇φ`、`H = (1/μ0)∇×A` を
  `1/R`・`1/R²`・`1/R³` の全項を残して評価します (遠方界のような漸近近似を
  しません)。地板があれば鏡像を加えるので、地板上で接線 E と法線 H が
  機械精度で 0 になります。EMC の近傍界スキャンやプローブ位置での結合量の
  見積り用です。
  `planewave` と併用すると、同じ観測点で平面波による誘起電流・電荷の散乱界に
  入射界 (地板があれば反射波も) を足した**全界**を `nearpw.csv` にも出します
  (列は `near.csv` と同じ)。導体の遮蔽効果 (シールド効果) や、外来波の中に
  置いた構造の周りの界分布を見る用途です。入射界は右辺の起電力と同じ
  規約 (`pw_waves()`) から組むので、到来方向・偏波・反射の符号が一致します。
- **平面波入射 (外部界励振)** — `planewave` キー :
  導体表面の電界積分方程式を区間に沿って線積分すると、枝方程式の右辺に
  誘起起電力 `-∫E_inc·dl` が立ちます。区間内は直線・一定方向なので線積分は
  `(E0ê·t̂) len exp(jk r̂·rc) sinc(k len(r̂·t̂)/2)` と厳密に評価でき、面セルは
  幅方向の平均にも同じ形の sinc が掛かります。`(θ, φ)` は**到来方向**
  (伝搬はその逆向き)。地板があるときは PEC 面の反射波を加算します。
  `pw.csv` に各ポートの端子電圧 (開放時は Voc)・実効長・利用可能電力を、
  `distribution = 1` なら `dist.csv` に誘起電流 (`Ipw`) を出します。
  EMC イミュニティ解析 (界 → 線路結合) 用です。
- **過渡応答** — `transient` キー :
  周波数掃引の結果 H(f) にガウスパルスのスペクトル X(f) を掛けて逆フーリエ
  変換し、時間波形を `tran.csv` に出します。掃引は `f_k = k·Δf` (等間隔かつ
  DC の整数倍、`frequency = Δf N·Δf N-1` と書く) が必須で、対数掃引は
  使えません。時間軸は `Δt = 1/(2f_max)`、全長 `1/Δf`、サンプル数 `2N`。
  出力は励振パルス (`X`)、S 行列各成分の時間応答 (`S` = TDR / 伝送)、
  平面波による誘起端子電圧 (`V`)。DC 項は実数条件のもとで下 2 点から
  線形補外します。第 2 引数で帯域端のガウス減衰 [dB] を指定でき
  (既定 40)、大きくするほどパルスが時間方向に広がります。
- **誘電体ブリック (Ruehli の過剰容量)** — `dielectric` キー :
  直方体の誘電体を 3 次元格子の体積セル (3 方向の枝) に分割し、各枝に
  過剰容量 `C_e = ε0(εr−1)A/len` の直列インピーダンス `1/(jωC_e)` を
  置きます (分極電流の枝)。真空部の結合は電位係数 P が受け持つので
  二重計上はありません。節点の束縛電荷が P に参加し、導体と接する面の
  ノードは `nodetol` マージで導体ノードと共有されます (経路が閉じる)。
  枝は Lp にも参加するのでフルウェーブでも整合します。`capacitance = 1`
  が必須です。平行平板間の ΔC = (εr−1)ε0A/d が格子に依らず厳密に
  再現されます (検証で実測残差 ~1e-6)。損失は一定 tanδ か、周波数分散
  (Debye 緩和極と Lorentz 共振極の任意の組合せ) で指定します。

### 制限 / Limitations

- `tline` は一様な TEM 線路です。Z0/遅延の形は無損失または一定減衰の
  無ひずみ線路、`rlgc` の形は表皮効果 (√f) と誘電損 (tanδ) を持つ損失線路で、
  L と C は周波数に依りません (内部インダクタンスの周波数変化や基板の分散は
  持ちません)。
  線路は幾何を持たないので、遠方界・近傍界・平面波入射とは結合しません
  (外部導体が完全に遮蔽している同軸に相当)。
- `skineffect` / `capacitance` / `retardation` は既定で無効です
  (キー省略時は従来動作と完全に一致)。
- `retardation = 0` は準静的モデルです。寸法 ≪ λ/10 で正確ですが、
  共振周波数は半波長共振より 15〜20% 高く出ます (`dipole_full.peec` 参照)。
  共振・放射を扱うなら `retardation = 1` を使ってください。
- 既定 (`basis = 0`) の電流は区間ごとに一定、電荷はセルごとに一定の低次基底です。共振近傍の
  精度は分割数に依存します (半波長ダイポールで片腕 16 分割 → Rin 誤差 0.5%、
  8 分割で 2.6%)。この互い違い格子は Rin について 2 次以上で収束します
  (片腕 4/8/16/32 分割の誤差 +7.9 / +1.9 / +0.37 / +0.02 Ω)。区分線形の
  電流基底 (`basis = 1`) は同じ列で −2.3 / −0.92 / −0.45 / −0.24 Ω と粗い格子で
  正確ですが、電荷が区分一定のままなので互い違い格子の対称性が崩れ、漸近的には
  1 次程度に落ちます。給電の無い散乱でも、細かい格子では従来の基底の方が正確です。
  電荷も高次にすると、節点電位をセル平均で定義する回路解釈 (集中定数・ポートが
  繋がる節点) と両立しません。粗い格子で済ませたい細線は `basis = 1`、精度を
  詰めるなら従来の基底で分割数を増やしてください。検討の数値は独立実装の
  `tools/basis_study.py` (純 Python) で再現できます。
  Xin はデルタギャップ給電のギャップ容量が格子を細かくすると対数的に増える
  (給電モデルの既知の性質) ので、収束の目安には Rin を使ってください。
- 角線は既定では等価半径による近似です。表皮効果の遷移域 (δ ~ 断面寸法) は
  両極限を繋ぐ合成式なので、その領域の精度や近接効果が要る用途では断面分割
  (`分割数w 分割数t`) を使ってください。丸線 (`wire`) は既定では表皮効果を
  Bessel の閉形式 (孤立線として厳密) で扱い、近接効果は扱いません。近接効果が
  要るときは断面分割 (`断面分割数`) を使ってください。
- 体積セル (角線・丸線の断面分割、`plate` の厚み分割) の Hoer–Love 閉形式は
  64 項の交代和で、細長いセルでは桁落ちします (条件数 ~ (区間長/セル幅)³、
  区間長/セル幅 = 500 で L に 1e-7、5000 で 5e-5 の雑音)。断面を細かく
  分割するときは長さ方向の `分割数` も増やし、区間長をセル幅の数百倍以下に
  してください。
- 面導体は平面パネルのみ : 矩形 (`plate`)、凸四辺形 (`quad`)、円板
  (`disk`)。他の形状はこれらの組合せ、3 次元曲面 (円筒など) は平面
  パネルのファセット化で近似します (パネル境界の格子点座標が `nodetol`
  以内で一致すればノードが共有されます)。plate の厚さ方向は既定で 1 層
  で、その場合の表皮効果は角線と同じ合成式を面セルの断面 (幅 × 厚さ)
  に適用します。厚み方向の電流分布を解くには `分割数t` ≥ 2 (体積セル)
  を使ってください (層厚 ≲ δ/2 で表皮効果を分解できます)。体積セルの
  閉形式は軸・断面がそろった平行バー対に適用し、それ以外の対 (斜め配置
  など) は中立面リボンの面積分に落ちます。
- `quad` / `disk` パネルの厚み方向分割 (`分割数t`) は、各層を厚みのない多角形の
  面積分で結合します (plate の層は Hoer–Love の体積閉形式)。層数の少ないところの
  誤差が plate より大きいので、厚み方向の表皮効果を見るときは層を多めに取って
  ください (検証では 6/12/24 層で補外)。
  パネルの DC 抵抗は格子の双対幅から決まり、矩形格子では厳密、歪んだ
  格子・極格子では O(格子幅²) の離散化誤差を含みます。表皮効果は `plate`
  と同じ合成式を断面 (双対幅 × 厚さ) に適用します (面内の再配分は格子が
  解くので、ここで見ているのは厚み方向のみ)。
- 導体は直線区間・平面パネルのみ (曲線は折れ線・ファセットで近似)。らせんと
  円形ループは `helix` キーが折れ線に展開します (1 周あたりの区間数は、区間長が
  線半径の数倍以上になるように取ってください)。
- 地板 (`groundplane`) は軸に垂直な無限 PEC 面で、互いに直交する 3 枚までです
  (平行な 2 面・斜めの面は不可)。有限サイズ・有限導電率の地板は `plate` で
  モデル化してください (鏡像との併用は可)。板のセル幅を導体の高さ以下にすると、
  一辺 16h の板で鏡像法の容量に 0.15% まで近づきます (`finite_gp.peec`)。x / y 面の遠方界は面の手前の半空間を
  φ の台形則 (面上は重み 1/2) で積分するので、`farfield` の φ 分割数は 4 の
  倍数にして面上 (φ = ±90° など) を格子点に載せてください。
- 遠方界 (`farfield`) の `far.csv` は port #1 の 1 A 励振 (または `excitation` の
  電流励振の重ね合わせ。電圧源・内部インピーダンス付きの給電は回路素子で組む)
  に対する値です。指向性 D は
  電流分布だけで決まりますが、利得 G と効率は導体損を含みます。平面波併用時の
  `farpw.csv` は誘起電流による散乱界のみ (入射波は含みません)。地板があると
  入射が直接波と反射波の 2 波になるので、光学定理の消光断面積は出しません
  (RCS と全散乱断面積は上半球で出します)。
- 近傍界 (`nearfield`) の `near.csv` は port #1 の 1 A 励振 (または `excitation`)、`nearpw.csv` は
  平面波入射時の全界 (入射 + 反射 + 散乱) です。入射界は物理的な平面波なので
  `retardation` に依らず k = ω/c で評価し、散乱界は以下の規約に従います。
  セル上の積分はセルあたり数点の求積なので、観測点はセル寸法程度以上離してください
  (セル上・セル直近では求積誤差が残ります)。`capacitance = 0` では電荷が
  無いので E は `−jωA` の項だけになります。`retardation = 0` のときは
  部分要素と揃えて静的 (k = 0) に評価します。
- 平面波 (`planewave`) は 1 行が 1 方向・1 偏波の入射波で、複数行 (8 行まで) を
  書くと同時に入射させます (起電力・入射界・散乱界はすべて重ね合わせ)。
  `pw.csv` の実効長と `farpw.csv` の RCS は 1 行目の振幅で規格化し、光学定理の
  消光断面積は単一波 (地板なし) のときだけ出します (前方方向が 1 つに決まる
  ときだけ定義できる)。`pw.csv` はポート間に素子が無いときだけ Voc として読めます。
- 過渡応答 (`transient`) は掃引の逆フーリエ変換なので、応答が全長 `1/Δf`
  以内に減衰しないと巻き込み (時間領域エイリアス) が起きます。Q の高い
  共振があるときは分割数を増やして Δf を小さくしてください。帯域端の
  打ち切りによる残留リンギングは減衰 [dB] を上げると減ります。
- 誘電体 (`dielectric`) は直交直方体のみです。損失は一定 tanδ または
  多極分散 (Debye 極 Δε_k/(1+jf/f_k) と Lorentz 極
  Δε_k f_k²/(f_k²−f²+jf g_k) の任意の組合せ。どちらも因果的で KK 整合)
  のどちらかで指定します (併用は損失の二重計上になるため拒否されます)。
  導電性の項として Drude 項 −f_p²/(f²−jf g) (自由電子・ドープ半導体。直流導電率
  2πε0 f_p²/g) と一定の導電率 −jσ/(ωε0) (損失性基板) も同じ並びに書けます。
  この 2 つは直流で発散するので直流極限の和 ε∞ + ΣΔε_k = εr には入れません
  (枝のアドミタンスは直流で σA/len に収まり有限)。
  節点の束縛電荷は a–b 面内の双対矩形パネルで表すため、
  側面の束縛電荷は面直位置がセル幅の範囲で近似になります (表面電荷が
  a–b 面に支配的な配置 — 基板・平行平板など — で正確)。
- 既定では行列は密です。計算量は電流セル数 N と電荷セル数 M に対して
  O(N²+M²) の積分と O((N+M)³) の LU。遅延ありのときはこれが周波数ごとに
  必要になります。地板 (鏡像) は積分回数を 2^面数 倍にします (未知数は不変)。
  `compression = 1` で部分要素の充填・格納が O(kN log N) に落ち、前処理の
  Schur 補元も疎な LU (最小次数順序) になるので、**圧縮経路には O(N²) の
  項が残りません**。


- Linux / macOS / Windows (MSVC + Ninja) の 3 OS を CI で検証しています。
  あわせて Linux で ASan + UBSan (LeakSanitizer 有効) を掛けた `sanitize`
  ジョブを実行し、値の正しさとメモリ健全性を同時に判定しています。
- OpenMP は任意です (無くてもビルド・実行可能)。並列化しているのは
  **部分インダクタンス行列の充填・電位係数行列の充填・LU 分解の残余行列更新・
  GMRES の行列ベクトル積** の 4 箇所で、いずれも要素・行ごとに独立
  (順序依存の加算が無い。GMRES の内積・Gram-Schmidt は直列) なため
  **スレッド数によらず出力はビット単位で一致します**
  (`peec_check.sh` が `-n 1` と `-n 4` の完全一致を判定)。
  LU 支配的なケース (未知数 645、21 周波数掃引) で 4 スレッド 3.6 倍。
- **部分要素の充填** : 面セル・多角形セルの静的部は「内側の面積分は閉形式 +
  外側だけ Gauss 求積」の 2 段構成なので、外側の被積分関数はセルが離れるほど
  滑らかになります。そこで求積次数を中心間距離で落としています
  (リボン 8 → 4 → 2 点、多角形 7 点則 → 3 点則。自己項・隣接項は最高次)。
  20×20 分割の平板で充填 **3.1 倍**、18×18 分割のパネルで **1.5 倍**の
  高速化で、Zin の変化は 1e-8 以下です (細線・角線・誘電体は完全に不変)。
  未知数がおよそ 7500 を超えると LU が充填を追い越します。
- **縁寄せ格子 (`grading = 1`)** : 面格子の縁では電荷密度が ~1/√d で
  特異になり、一様格子の容量収束は O(h) に留まります。`grading = 1` で
  格子点を縁に寄せ (plate/quad は余弦分布、disk は正弦分布で外周寄せ)、
  同じ未知数で精度を上げます。セルの幅・中心・電荷セルはすべて格子座標の
  隣接中点 (双対区間) から導くので、非一様でも面は重複なく張られ、矩形
  格子の DC 抵抗の厳密性も保たれます。平板容量で 8×8 縁寄せ (−0.45%) が
  16×16 一様 (−0.68%) を上回ります (未知数 1/4 で精度向上)。`node =` で
  格子点に接続する場合は縁寄せ後の座標に置いてください。
- **周波数掃引の加速 (`acceleration = 1`)** : 直近に LU 分解した行列を
  右前処理に使う GMRES で各周波数を解き、収束しないときだけ LU を取り
  直します。掃引点が密なほど O(N³) の LU の回数が減り、**最悪でも従来の
  毎周波数 LU と同等**です (自動フォールバック)。結果は密 LU と実質同一
  (収束判定 1e-10、実測差 ~1e-10 以下)。未知数 1825・50 周波数の掃引で
  solve 62.9 s → 6.2 s (LU 1 回、平均 5.8 反復)。遅延あり (行列が毎周波数
  変わる場合) でも使えます。既定 (省略時 0) は従来どおりです。
- **H 行列圧縮 (`compression = 1 [tol]`)** : 密行列を一切作らない
  行列フリー経路です。部分インダクタンス Lp をクラスタツリー + ACA
  (Adaptive Cross Approximation) で階層的低ランク圧縮し、MNA の疎な部分は
  三つ組で持ち、葉ブロック消去 + 回路 Schur 補元を前処理とする GMRES で
  解きます。ACA の相対許容誤差 `tol` (省略時 1e-6) が Zin にほぼそのまま
  伝わります (実測 : tol 1e-6 で ~3e-7、1e-8 で ~5e-10)。6384 セルの平板で
  **solve 12 分 → 52 秒 (14 倍)、メモリ 2.0 GB → 0.34 GB (6 倍)**。
  自己項・隣接項 (近傍ブロック) は一切近似されません。
  `capacitance = 1` (容量性・フルウェーブ PEEC) にも対応しており、
  そのときは電位係数 P も同じ機構で圧縮します。節点容量 C = P⁻¹ は
  密な逆行列なので作らず、**電荷 q を陽な未知数**にして
  「KCL に + jωq」「電荷行に Pq − v = 0」と組みます (電荷行から
  q = P⁻¹v なので密経路と同じ系。近似が入らない規模では両経路の Zin が
  ビット単位で一致することを検証しています)。`acceleration` とは排他です。
  結果はスレッド数に依らずビット単位で一致します。
  前処理の **Schur 補元も疎行列** として持ちます。葉が触れる回路未知数は
  幾何的に局所的なので、Schur は 1 行あたりの非ゼロ数が規模によらず ~36 に
  飽和し (実測)、最小次数順序 + Gilbert-Peierls の LU で厳密に分解できます。
  近似ではなく厳密な分解なので GMRES の反復数も収束先も変わらず、
  メモリと時間だけが減ります (56×56 の平板で **382 MB → 224 MB、
  17.5 秒 → 9.3 秒**、Zin は密 Schur 版とバイト単位で一致)。

### HDF5 への変換 (画面表示・後処理用)

ソルバー本体は外部ライブラリに依存しない方針なので、HDF5 化は同梱の変換
スクリプトが受け持ちます。**ビルドには不要**で、使うときだけ numpy と h5py
が要ります。

```bash
pip install numpy h5py
peec input.peec                       # CSV 一式が出る
python tools/peec2h5.py . -o peec.h5  # 単位つきで 1 個の HDF5 にまとめる
python3 tools/basis_study.py 4 8 16  # 電流基底の次数の検討 (basis = 1 の参照値)
```

`/frequency`, `/zin`, `/sparam`, `/transient/{time,excitation,s,v}`,
`/planewave/{voc,leff,pav}`, `/farfield/{theta,phi,e_theta,e_phi,d,g}`,
`/distribution/<type>/{position,value,frequency}` の構造で書き出します
(あるファイルだけ変換)。各データセットは `units` 属性を持ちます。

**多ポート解析** : `port` を複数書くと、ポート j に 1A を注入し (他ポートは
開放) 全ポートの端子電圧を読むことで Z 行列を求め、電力波の定義 (Kurokawa)

```
S = F (Z − Z0) (Z + Z0)⁻¹ F⁻¹,   F = diag(1 / (2√z0ᵢ))
  → Sᵢⱼ = √(z0ⱼ / z0ᵢ) · [(Z − Z0)(Z + Z0)⁻¹]ᵢⱼ
```

で S 行列に変換します。基準抵抗 `z0` は `port` キーでポートごとに指定でき、
全ポートで等しいときは教科書どおりの `(Z − Z0)(Z + Z0)⁻¹` に一致します。
Touchstone 1.1 は基準抵抗を 1 個しか記録できないため、ポートごとに異なる
`z0` を与えた場合は port#1 の値を書き、その旨をコメント行に残します。

**混合モード S パラメータ** : `mixedmode = p1 n1 [p2 n2 ...]` で単端ポートの
対 (正側, 負側) を差動対にすると、電力波を
`a_d = (a_p − a_n)/√2`、`a_c = (a_p + a_n)/√2` に組み替えた混合モード S 行列

```
S_mm = M S Mᵀ   (M は直交行列 : 差動対ごとに ±1/√2、対に入らないポートは 1)
```

を `mixed.csv` と `peec.log` に出します (Bockelman & Eisenstadt の定義)。並びは
d1..dP、c1..cP、対に入らない単端ポート (番号順) で、例えば 2 対の 4 ポートでは
`S(d2,d1)` = Sdd21 (差動伝送)、`S(c2,d1)` = Scd21 (差動 → 同相のモード変換)。
基準抵抗は差動モード 2·z0、同相モード z0/2 で、これが成り立つよう対の 2 ポートの
`z0` は等しくなければなりません (入力検査で拒否します)。

テキスト形式。1 行目は `OpenPEEC 1 0`、最終行は `end`。`#` はコメント。
ノード id は非負整数で **0 = GND (基準)**。単位はすべて SI。

- 導体と回路素子の接続は `node` キーで行います。導体端点 (面導体は格子点)
  の座標が `nodetol` 以内で一致するとそのノード id に接続されます。
- `plate` は原点 `o` と 2 辺ベクトル `a`, `b` で矩形 `o + s·a + t·b`
  (s,t ∈ [0,1]) を表します。格子点は `o + (i/分割数a)·a + (j/分割数b)·b`。
- ワイヤ内部の分割点は最大ノード id + 1 から記載順に自動採番されます
  (決定的)。
- 基準ノードはノード 0。`capacitance = 0` でノード 0 が使われていない場合は
  port #1 の n2 を基準にします (浮遊回路の特異回避)。`capacitance = 1` では
  常にノード 0 (= 無限遠) が基準です (上記「遅延」参照)。ログに表示されます。
- 未知のキーは無視されます (前方互換)。キー省略時の既定値は従来動作と
  一致します (後方互換)。
