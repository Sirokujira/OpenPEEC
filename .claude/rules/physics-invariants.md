# 壊してはいけない物理・数値の不変条件

どれも「壊れても実行は通るが、結果が静かに (あるいは派手に) 狂う」種類のもの。
いずれも `peec_check.sh` の特定の判定が番人になっている。

## (1) 幾何カーネルの統一

`neumann_pair()` / `neumann_self()` は同一の細線縮約カーネル
`R = sqrt(|dr|^2 + a^2)` を使う。この統一により `Σᵢⱼ Iᵢⱼ = I_self(全長)` が
厳密に成立し、次の 2 つが保証される。

- 直線導体の合計インダクタンスが分割数に依存しない
- 対無限遠容量が平均電位法の解析解と厳密に一致する

**番人**: `wire L (ndiv=1)` / `wire L (ndiv=8)` / `wire Ctotal` (許容 0.1%)

片方の項だけ正則化を変えると両方が静かに劣化する。

## (2) 静的部と遅延補正部で評価法を揃える

放射抵抗は L 項と P 項の**大きな値どうしの差**として現れる。片方だけ
中点近似などに切り替えるとその差が汚染される。`neumann_pair_k()` は
解析式が厳密な平行区間以外では静的部も補正部と同じ求積で評価している。

**番人**: `short dipole R_rad` / `dipole Rin at res.`

## (3) 容量ありのときは実ノードを接地しない

容量の電位基準は無限遠。実ノードを接地するとそこから無限遠へ電荷が逃げる
経路ができ、構造の総電荷が保存しなくなる。準静的では影響は無視できるが、
遅延ありでは放射抵抗の打ち消し (`Σq = 0`) が壊れ **Rin が負になる**
(実際に踏んだ: 微小ダイポールで Rin = −23 Ω)。

`mna_numbering()` は `capacitance = 1` のとき基準を必ずノード 0 (= 無限遠)
にし、ノード 0 が未使用ならどの実ノードも消去しない。

例外は地板 (`groundplane`) があるとき。鏡像電荷 −q が総電荷の保存
(構造 + 鏡像で Σq = 0) を自動で満たすため、ノード 0 (= 地板電位) に
ポートを繋いでよい (モノポール給電)。

**番人**: `short dipole R_rad` (負の抵抗が出たら即座に落ちる) /
`monopole Rin at res.` (地板の例外側)

## (4) 面セルの幅による規格化

面導体セルは幅で規格化した `Î = (1/(w₁w₂))∬∬dS dS′/R` を返す。これにより
w→0 が細線の `∬dl dl′/R` に一致し、`Lp` と `P` の式を細線と共有できる。
規格化を崩すと細線と面導体で式を分岐させる羽目になる。

**番人**: `strip L (surface)` (面積分と細線 GMD 近似の相互検証)

## (5) 電荷セルは幾何段で明示的に作る

電流セル (`p->seg`) と電荷セル (`p->chg`) は `wire.c` が作る。線導体の電荷
セルは区間の半分、面導体は格子ノードの双対矩形。**面導体で「電流セルの半分」
から電荷セルを導出すると面内 2 方向ぶん二重計上になる**。

**番人**: `plate C (extrapolated)`

## (6) 体積カーネルのゼロ引数ガードと加法性

Hoer-Love の原始関数 `hl_F(x,y,z)` (volume.c) では、引数が 0 のとき
**係数が消える項だけ**を 0 にする。`F(0,y,z)` は x を因子に持つ項が
消えるだけで、残りの項は有限に残る。「引数に 0 があるから」と F 全体を
0 にすると、自己項 (E = P = l3 = 0) が約 38 倍ずれ、重なり配置への移行が
不連続になる (実際に踏んだ)。対数項は `log((x+R)/√(y²+z²))` ではなく
`asinh(x/√(y²+z²))` と書く (等価だが x < 0 で桁落ちしない)。

正しく実装すると体積を分割した部分和が全体に一致する加法性が機械精度で
成り立ち、次の 2 つが保証される。

- 厚板の合計インダクタンスが分割数 (長さ・幅・厚みとも) に依存しない
- 共有ノードで並列になった層の DC 抵抗が層数に厳密に依存しない

また、体積セルの厚み方向の電流再配分は Lp 行列が陽に解くので、
`zint_seg()` は体積セルに表皮効果の合成式を適用しない (二重計上になる)。
内部インダクタンスも体積自己項に含まれている。

**番人**: `thick plate L (Grover)` / `thick plate R (ndivt=1/2)` /
`slab skin ratio (extr.)` / `slab skin convergence`

## (7) 多角形セルの規格化と桁落ちフリーの対数項

パネル (quad/disk) のセルは一般四辺形・双対多角形になる。

- 規格化は `w̄ = 面積/len` で不変条件 (4) の一般化。`len·w̄ = 面積` なので
  `P = Î/(4πε0 L₁L₂) = ∬∬/(4πε0 A₁A₂)` が細線・リボンと同じ式のまま
  成り立つ。矩形格子では plate のセル・値に一致する (`quad sheet L vs
  plate` が 1e-5 レベルで一致することを確認済み)。
- `poly_potential()` (polygon.c) の対数項 `ln((R⁺+l⁺)/(R⁻+l⁻))` は、
  l < 0 の側を恒等式 `R + l = R0²/(R − l)` で計算する。素朴に和を取ると
  隣接セルの求積点が共有辺の延長線近傍に乗ったとき R と |l| が倍精度で
  一致して 0 になり、log が ±inf → MNA の 0 × inf で **NaN** になる
  (実際に踏んだ : 極格子の半径方向セルと周方向セルは辺を共有する)。
- パネルセルの DC 抵抗は格子の双対幅 (幾何) から取る。重なりのない
  三角形辺基底に変えると一様シート流の散逸を約 2 倍に過大評価する
  (構造直角三角形格子で厳密に 2 倍。試して棄却済み)。構造四辺形格子
  では幾何幅で厳密。
- 断面が plate と同じ幾何量 (双対幅 × 厚さ) なので、**表皮効果も plate と
  同じ合成式を適用する**。合成式の DC 極限は `s->res` に厳密に一致するので
  不連続は生じない。以前は「DC 抵抗が cotangent 重みで決まるから」という
  理由で除外していたが、DC 抵抗を幾何双対幅に変えた時点でその理由は消えて
  いた (コメントだけが残っていた)。適用しないでいると厚み方向の表皮効果
  (δ < thick) が丸ごと落ち、1 GHz・厚さ 0.1 mm の銅シートで plate 比 −24%
  になる。面内の再配分は格子が解くので、ここで見ているのは厚み方向のみ。

**番人**: `quad sheet Rin (DC)` / `quad sheet L vs plate` /
`quad sheet R vs plate (HF)` / `quad sheet R (skin at DC)` /
`disk C (extrapolated)` / `annulus Rin (DC)`

## (8) 鏡像の符号規約 (groundplane)

鏡像セルは**幾何鏡像** (z → 2 gpz − z、wv の z 反転、pv/papex も鏡像) を
`seg_mirror()` (partial.c) で作り、

- Lp : 相互項 `(t₁·t₂′) I(s₁, M s₂)` を**減算**する (t₂′ は鏡像の幾何方向)。
  これが「鏡像電流 = 水平成分反転・垂直成分保存」と同値になる。
  幾何方向のまま加算する・減算を忘れる・水平垂直を取り違えると、
  水平線の L 減少 / 垂直線の L 増加がそれぞれ逆転する。
- P : 鏡像電荷は −q なので相互項をそのまま減算する。
- 自己項 (対角) も自分の鏡像との相互項を引くこと。忘れると高さ依存が消える。
- 遠方界 (farfield.c) の鏡像は「鏡像位置 + t′ + 電流 −I」で同じ規約。

M は等長変換かつ対合なので I(s₁, M s₂) = I(M s₁, s₂) が成り立ち、
行列の対称性は保たれる (片側だけ鏡像を取ってよい根拠)。

**番人**: `wire-gp L (images)` / `wire-gp C (to plane)` /
`monopole = dipole/2` (λ/4 モノポール = 半波長ダイポール/2 が離散化レベルで
一致することが、L・P・遅延・給電のすべての符号を同時に判定する)

## (9) 誘電体は εr − 1 だけを枝に載せる (二重計上禁止)

真空 (ε0) の結合は電位係数 P が受け持ち、誘電体の枝は**過剰分
C_e = ε0(εr−1)A/len だけ**を直列インピーダンス 1/(jωC_e) として持つ
(mna.c が `seg->diel` を見て入れる。skin の合成式は適用しない)。
εr をそのまま使うと真空部を二重計上する。

εr = 1 のブリックは**セルを作らない** (input_data.c でスキップ)。
作ると C_e = 0 → 1/(jω·0) = inf で NaN になる。スキップすれば
真空と bit 単位で一致する。

損失 (tanδ) も同じ原則で、複素比誘電率 εr* = εr(1 − j tanδ) の**過剰分
だけ**を枝に載せる :

  Y = jω ε0 (εr* − 1) A/len = ω (gexc + j cexc)
  gexc = ε0 εr tanδ A/len,  cexc = ε0 (εr − 1) A/len

損失側の係数が (εr − 1) ではなく **εr** である点に注意 (εr* − 1 の虚部は
−εr tanδ)。tanδ = 0 なら Z = −j/(ωC_e) で従来と bit 単位で一致する。

周波数分散 (単極 Debye、`frelax > 0`) も同じ原則で、周波数ごとの
εr\*(f) = ε∞ + (εs−ε∞)/(1+jf/fr) から **過剰分 (εr\*−1) だけ**を
`zint_diel()` (mna.c) が組む。定数 tanδ と Debye の併用は損失の二重計上
なので入力検証で拒否する (Debye の損失は緩和そのものが生む)。
ε∞ は 1 ≤ ε∞ ≤ εs (緩和で誘電率は下がる)。

**番人**: `dielectric dC (pp)` (等電位面間の過剰容量ラダーは格子に依らず
厳密に (εr−1)ε0A/d になる : 実測残差 ~1e-6) / `dielectric epsr=1 noop` /
`dielectric G (tand)` (損失性平行平板の G = ωε0 εr tanδ A/d という
コード非依存の解析値。損失側を (εr−1) と取り違えるとここで 25% ずれる) /
`dielectric tand=0 noop` / `debye dY (3 freqs)` (ΔY(f) = jωε0(εr\*(f)−1)A/d
の 3 周波数 × 実部虚部。fr/100 と fr で ~2e-7、100fr は直列 L の準静的
補正が入り始めて ~5e-4)

## (10) 遠方界の規格化とポインティング整合

遠方界は r E = −j(ωμ0/4π)[N − (N·r̂)r̂]、放射強度 U = |rE|²/(2η0)。
この規格化が正しいことは Prad = ∮U dΩ が回路側の入力電力
Pin = Re(Zin)/2 と一致する (低損失アンテナで効率 ≈ 1) ことで判定される。
係数を触るとパターン形状 (D) は変わらず**効率だけが静かに狂う**。

**番人**: `dipole ff efficiency` (実測 1.0004) / `short dipole D` (= 1.5 厳密) /
`monopole D = 2 x dipole` (鏡像遠方界と上半球積分)

## (11) 送信と受信は相反定理で結ばれている (平面波入射)

平面波入射 (`mna_rhs_planewave`) と遠方界 (`farfield.c`) は独立な実装だが、
離散化した系でも次の恒等式が**厳密に**成り立つ :

  l_eff = N_t = rE · 2λ/(-j η0)     (1 A 給電時の放射ベクトル)
  Voc   = -E0 (ê·l_eff)

符号 (−) はポート規約による : `mna_rhs_port` は n1 に +1 A を注入する一方、
Voc は v(n1) − v(n2) で測るため基準の向きが逆になる。**この符号は角度・偏波
によらず厳密に −1 倍**で、非対称構造の複数方向で確認済み (バグなら一定倍率に
ならない)。両者は位相規約 exp(+jk r̂·r)、sinc 積分、偏波ベクトル、鏡像規約を
共有しているので、片方だけ触ると必ずここが落ちる。

**番人**: `recip 30/45/p1` ほか 5 方向 × 偏波 (実測 ~3e-10) と
`recip 60/0/p1` (地板あり = 鏡像の送受一致)。振幅の絶対値は
`dipole pw leff` (= λ/π) と `loop pw |Voc|` (= kE0A) が別途アンカーする。

## (12) 過渡応答は exp(+jωt) 規約と等間隔掃引に依存する

`transient.c` の合成 y(t) = df[H(0)X(0) + 2ReΣH(f_k)X(f_k)e^{j2πf_k t}] は
コードベース全体の exp(+jωt) 規約 (inductor が +jωL) と一致していなければ
ならない。**純抵抗の判定 (S11 が実数) では共役の取り違えを検出できない**ので、
周波数依存のあるケースが必要になる。微小ループは Voc ∝ jω なので時間波形が
励振の微分になり、共役を取り違えると符号が反転する。

掃引は f_k = k·df (等間隔かつ DC の整数倍) でなければ時間軸が定義できない。
`tran_check()` がこれを検査し、対数掃引は明示的に拒否する。DC 項は掃引に
含まれないので、実数条件 Im H(0) = 0 のもとで下 2 点から線形補外する。

**番人**: `loop transient (d/dt)` (規約の一貫性) / `tdr R=...` 4 通り
(合成の線形性・スケール・符号) / `transient sweep guard` (掃引の検査)

## (13) 外側求積の次数は距離だけで決めてよい (内側が解析的に厳密だから)

面セル (リボン) と多角形セルの静的部は「内側の面積分は閉形式 + 外側だけ
Gauss 求積」という 2 段構成になっている。内側が厳密なので外側の被積分関数は
セルが離れるほど滑らかになり、必要な次数は**中心間距離 / セル寸法の比だけ**で
決まる。この性質を使って `ribbon_nq()` (partial.c) は 8 → 4 → 2 点、
`POLY_R7` は 7 点則 → 3 点則へ落としている。実測相対誤差 (基準は最高次) :

    d/h        1        2        5       10
  リボン 4 点  -2.7e-4  -8.4e-10 -7.7e-11 -2.9e-13
  リボン 2 点  -3.6e-3  -3.6e-05 -1.2e-05 -7.7e-07

**次数を落としてよいのは静的部だけ**で、自己項・隣接項 (比 <= 2.5) は最高次を
使う。ここを緩めると (4) の幅規格化と (6) の加法性が同時に劣化する。

不変条件 (2) との関係 : 遅延補正部は次数を変えていない。静的部の変更が放射
抵抗の打ち消しを汚さないことは、遅延あり面セル (平板ストリップ) で
Rin 942.8985 → 942.8986 Ω (相対 1.4e-7) と確認済み。(2) が守るのは中点近似の
ような O(1%) の系統差であって、この水準は問題にならない。

**番人**: `quad sheet L vs plate` (多角形経路とリボン経路の相互検証、許容
0.1% に対し実測 1e-5 レベル。両経路の求積を独立に粗くしているので、
片方が壊れるとここに出る) / `strip L (surface)` / `plate C (extrapolated)` /
`disk C (extrapolated)`

## (14) 非一様格子の幾何は格子座標の隣接中点 (双対区間) から導く

縁寄せ格子 (`grading = 1`) で plate のセル幅・中心・電荷セルは、格子座標
配列 xa[]/xb[] の隣接中点で決まる双対区間 [lo, hi] から導く :

  lo = (j == 0) ? x[0] : (x[j-1]+x[j])/2,  hi = (j == n) ? x[n] : (x[j]+x[j+1])/2

こうすると非一様でも面が重複なく張られ (Σwid = 全幅が厳密)、矩形格子の
DC 抵抗の厳密性 (不変条件 7 の plate 版) が保たれる。quad/disk はセルが
すべて格子点座標から導かれる構造なので `panel_node()` のパラメータ変換
(余弦 / 正弦) だけで整合する。等間隔時の座標式は従来と同一 (`i*h`) に
してあるので、キー省略時は完全後方互換。

**注意** : `node =` で格子点に接続する検証ケースは、縁寄せ後の座標に
ノードを置くこと。座標が食い違うと nodetol マージが外れて**接続が静かに
切れ**、quad 1 スクエアの DC が +46% ずれる (実際に踏んだ。
quad_square_graded.peec は余弦位置を 16 桁で記載している)。

**番人**: `graded quad Rin (DC)` / `graded quad L vs plate` (多角形経路と
矩形リボン経路が同一の非一様格子を作ること) / `graded thick plate R`
(体積セル併用) / `graded plate C (8x8)` / `graded8 beats uniform16`
(縁寄せの存在意義 : 未知数 1/4 で等間隔 16x16 を上回る)

## 並列化

`lp_fill` / `pot_fill` は OpenMP 並列。並列ループ内で共有配列に `+=` しない
(`pot_fill` は積分結果を一時配列に出してから直列で集約している)。
スレッド数によらず出力がビット一致することを必ず確認する。
