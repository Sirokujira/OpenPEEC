# 壊してはいけない物理・数値の不変条件

どれも「壊れても実行は通るが、結果が静かに (あるいは派手に) 狂う」種類のもの。
いずれも `peec_check.sh` の特定の判定が番人になっている。

## (1) 幾何カーネルの統一

`neumann_pair()` / `neumann_self()` は同一の細線縮約カーネル
`R = sqrt(|dr|^2 + a^2)` を使う。この統一により `Σᵢⱼ Iᵢⱼ = I_self(全長)` が
厳密に成立し、次の 2 つが保証される。

- 直線導体の合計インダクタンスが分割数に依存しない
- 対無限遠容量が平均電位法の解析解と厳密に一致する

**番人**: `wire L (ndiv=1)` / `wire L (ndiv=8)` / `wire Ctotal` (許容 0.1%)

片方の項だけ正則化を変えると両方が静かに劣化する。

## (2) 静的部と遅延補正部で評価法を揃える

放射抵抗は L 項と P 項の**大きな値どうしの差**として現れる。片方だけ
中点近似などに切り替えるとその差が汚染される。`neumann_pair_k()` は
解析式が厳密な平行区間以外では静的部も補正部と同じ求積で評価している。

**番人**: `short dipole R_rad` / `dipole Rin at res.`

## (3) 容量ありのときは実ノードを接地しない

容量の電位基準は無限遠。実ノードを接地するとそこから無限遠へ電荷が逃げる
経路ができ、構造の総電荷が保存しなくなる。準静的では影響は無視できるが、
遅延ありでは放射抵抗の打ち消し (`Σq = 0`) が壊れ **Rin が負になる**
(実際に踏んだ: 微小ダイポールで Rin = −23 Ω)。

`mna_numbering()` は `capacitance = 1` のとき基準を必ずノード 0 (= 無限遠)
にし、ノード 0 が未使用ならどの実ノードも消去しない。

例外は地板 (`groundplane`) があるとき。鏡像電荷 −q が総電荷の保存
(構造 + 鏡像で Σq = 0) を自動で満たすため、ノード 0 (= 地板電位) に
ポートを繋いでよい (モノポール給電)。

**番人**: `short dipole R_rad` (負の抵抗が出たら即座に落ちる) /
`monopole Rin at res.` (地板の例外側)

## (4) 面セルの幅による規格化

面導体セルは幅で規格化した `Î = (1/(w₁w₂))∬∬dS dS′/R` を返す。これにより
w→0 が細線の `∬dl dl′/R` に一致し、`Lp` と `P` の式を細線と共有できる。
規格化を崩すと細線と面導体で式を分岐させる羽目になる。

**番人**: `strip L (surface)` (面積分と細線 GMD 近似の相互検証)

## (5) 電荷セルは幾何段で明示的に作る

電流セル (`p->seg`) と電荷セル (`p->chg`) は `wire.c` が作る。線導体の電荷
セルは区間の半分、面導体は格子ノードの双対矩形。**面導体で「電流セルの半分」
から電荷セルを導出すると面内 2 方向ぶん二重計上になる**。

**番人**: `plate C (extrapolated)`

## (6) 体積カーネルのゼロ引数ガードと加法性

Hoer-Love の原始関数 `hl_F(x,y,z)` (volume.c) では、引数が 0 のとき
**係数が消える項だけ**を 0 にする。`F(0,y,z)` は x を因子に持つ項が
消えるだけで、残りの項は有限に残る。「引数に 0 があるから」と F 全体を
0 にすると、自己項 (E = P = l3 = 0) が約 38 倍ずれ、重なり配置への移行が
不連続になる (実際に踏んだ)。対数項は `log((x+R)/√(y²+z²))` ではなく
`asinh(x/√(y²+z²))` と書く (等価だが x < 0 で桁落ちしない)。

正しく実装すると体積を分割した部分和が全体に一致する加法性が機械精度で
成り立ち、次の 2 つが保証される。

- 厚板の合計インダクタンスが分割数 (長さ・幅・厚みとも) に依存しない
- 共有ノードで並列になった層の DC 抵抗が層数に厳密に依存しない

また、体積セルの厚み方向の電流再配分は Lp 行列が陽に解くので、
`zint_seg()` は体積セルに表皮効果の合成式を適用しない (二重計上になる)。
内部インダクタンスも体積自己項に含まれている。

角線 (`bar`) の断面分割 (`分割数w 分割数t`) も同じ体積セルを使う。区間を
nw × nt の矩形バーの並列に置き換え、どれも区間の両端ノードを共有する
(断面ごとに 1 ノード = VFI)。局所枠は幅 wv = ẑ × 軸 (水平、軸が z と平行なら
x̂)、厚み nv = 軸 × wv で、平行に並んだ 2 本の角線は同じ wv を持つので
Hoer–Love の対 (bar_use_hl) に乗る。電荷セルは分割前の区間のまま (表面電荷の
断面分布は扱わない)。加法性は長さ/断面 ~ 2000 の細長いセルで閉形式の和に
桁落ちが出て 1e-6 程度になる (L の分割数不変性の判定はこのため 2e-5)。

**番人**: `thick plate L (Grover)` / `thick plate R (ndivt=1/2)` /
`slab skin ratio (extr.)` / `slab skin convergence` / `bar sub Rin (DC)` /
`bar sub L (Grover)` / `bar sub L (10x4 = 5x2)` / `bar slab ratio (extr.)` /
`bar slab convergence` / `bar slab = plate slab` (2 次元格子の plate と断面ごと
1 ノードの角線という別経路の離散化が 0.07% で一致)

## (7) 多角形セルの規格化と桁落ちフリーの対数項

パネル (quad/disk) のセルは一般四辺形・双対多角形になる。

- 規格化は `w̄ = 面積/len` で不変条件 (4) の一般化。`len·w̄ = 面積` なので
  `P = Î/(4πε0 L₁L₂) = ∬∬/(4πε0 A₁A₂)` が細線・リボンと同じ式のまま
  成り立つ。矩形格子では plate のセル・値に一致する (`quad sheet L vs
  plate` が 1e-5 レベルで一致することを確認済み)。
- `poly_potential()` (polygon.c) の対数項 `ln((R⁺+l⁺)/(R⁻+l⁻))` は、
  l < 0 の側を恒等式 `R + l = R0²/(R − l)` で計算する。素朴に和を取ると
  隣接セルの求積点が共有辺の延長線近傍に乗ったとき R と |l| が倍精度で
  一致して 0 になり、log が ±inf → MNA の 0 × inf で **NaN** になる
  (実際に踏んだ : 極格子の半径方向セルと周方向セルは辺を共有する)。
- パネルセルの DC 抵抗は格子の双対幅 (幾何) から取る。重なりのない
  三角形辺基底に変えると一様シート流の散逸を約 2 倍に過大評価する
  (構造直角三角形格子で厳密に 2 倍。試して棄却済み)。構造四辺形格子
  では幾何幅で厳密。
- 断面が plate と同じ幾何量 (双対幅 × 厚さ) なので、**表皮効果も plate と
  同じ合成式を適用する**。合成式の DC 極限は `s->res` に厳密に一致するので
  不連続は生じない。以前は「DC 抵抗が cotangent 重みで決まるから」という
  理由で除外していたが、DC 抵抗を幾何双対幅に変えた時点でその理由は消えて
  いた (コメントだけが残っていた)。適用しないでいると厚み方向の表皮効果
  (δ < thick) が丸ごと落ち、1 GHz・厚さ 0.1 mm の銅シートで plate 比 −24%
  になる。面内の再配分は格子が解くので、ここで見ているのは厚み方向のみ。

**番人**: `quad sheet Rin (DC)` / `quad sheet L vs plate` /
`quad sheet R vs plate (HF)` / `quad sheet R (skin at DC)` /
`disk C (extrapolated)` / `annulus Rin (DC)`

## (8) 鏡像の符号規約 (groundplane)

鏡像セルは**幾何鏡像** (z → 2 gpz − z、wv の z 反転、pv/papex も鏡像) を
`seg_mirror()` (partial.c) で作り、

- Lp : 相互項 `(t₁·t₂′) I(s₁, M s₂)` を**減算**する (t₂′ は鏡像の幾何方向)。
  これが「鏡像電流 = 水平成分反転・垂直成分保存」と同値になる。
  幾何方向のまま加算する・減算を忘れる・水平垂直を取り違えると、
  水平線の L 減少 / 垂直線の L 増加がそれぞれ逆転する。
- P : 鏡像電荷は −q なので相互項をそのまま減算する。
- 自己項 (対角) も自分の鏡像との相互項を引くこと。忘れると高さ依存が消える。
- 遠方界 (farfield.c) の鏡像は「鏡像位置 + t′ + 電流 −I」で同じ規約。

M は等長変換かつ対合なので I(s₁, M s₂) = I(M s₁, s₂) が成り立ち、
行列の対称性は保たれる (片側だけ鏡像を取ってよい根拠)。

**番人**: `wire-gp L (images)` / `wire-gp C (to plane)` /
`monopole = dipole/2` (λ/4 モノポール = 半波長ダイポール/2 が離散化レベルで
一致することが、L・P・遅延・給電のすべての符号を同時に判定する)

## (9) 誘電体は εr − 1 だけを枝に載せる (二重計上禁止)

真空 (ε0) の結合は電位係数 P が受け持ち、誘電体の枝は**過剰分
C_e = ε0(εr−1)A/len だけ**を直列インピーダンス 1/(jωC_e) として持つ
(mna.c が `seg->diel` を見て入れる。skin の合成式は適用しない)。
εr をそのまま使うと真空部を二重計上する。

εr = 1 のブリックは**セルを作らない** (input_data.c でスキップ)。
作ると C_e = 0 → 1/(jω·0) = inf で NaN になる。スキップすれば
真空と bit 単位で一致する。

損失 (tanδ) も同じ原則で、複素比誘電率 εr* = εr(1 − j tanδ) の**過剰分
だけ**を枝に載せる :

  Y = jω ε0 (εr* − 1) A/len = ω (gexc + j cexc)
  gexc = ε0 εr tanδ A/len,  cexc = ε0 (εr − 1) A/len

損失側の係数が (εr − 1) ではなく **εr** である点に注意 (εr* − 1 の虚部は
−εr tanδ)。tanδ = 0 なら Z = −j/(ωC_e) で従来と bit 単位で一致する。

周波数分散 (多極 Debye / Lorentz、`npole > 0`) も同じ原則で、周波数ごとの
εr\*(f) = ε∞ + Σ_k χ_k(f) から **過剰分 (εr\*−1) だけ**を
`zint_diel()` (mna.c) が組む。極は 2 種類で、`plor[k]` が選ぶ :

- Debye   : χ_k = Δε_k/(1+jf/f_k)
- Lorentz : χ_k = Δε_k f_k²/(f_k²−f²+jf g_k) = Δε_k/(1−q²+jqr)
  (q = f/f_k、r = g_k/f_k。正規化形で組むので f_k² の桁あふれは無い)

導電性の項も同じ並びに書ける :

- Drude 項   : χ_k = −f_p²/(f²−jf g_k) (exp(+jωt) 規約の ε∞ − ωp²/(ω²−jωΓ))。
  直流導電率 σ_dc = 2πε0 f_p²/g_k。
- 導電率     : χ_k = −jσ/(ωε0) (Drude の g → ∞ 極限)。

この 2 つは f → 0 で −b が 1/f で発散するが、Y = ω ε0 gfac (−b + ...) の ω が
打ち消して Y → σA/len に収まる (分極電流の枝が伝導電流の枝になる)。
直流で発散するので**直流極限の和 ε∞ + ΣΔε_k = εr には入れない**
(和を取るのは Debye / Lorentz 極だけ)。損失側は b ≤ 0 で Debye / Lorentz と
同じ向き。導電性があれば εr = 1 でもセルを作る (作らないと導電性の基板が
黙って真空になる)。Drude の分母は f² で割った −(f_p/f)²/(1 − jg/f) の形で
組む (f_p² の桁あふれを避ける Lorentz の正規化と同じ考え方)。

定数 tanδ と分散の併用は損失の二重計上なので入力検証で拒否する
(分散の損失は極そのものが生む)。ε∞ は 1 ≤ ε∞ ≤ εs (Δε_k > 0 の和だけ下がる)。
Lorentz 極は共振の少し上で εr′ < 1 (さらに負) になり得て、そのとき枝の
サセプタンスは誘導性になる。g_k > 0 なら損失 −b > 0 が残るので Y は 0 に
ならず Z = 1/Y は有限 (g_k = 0 の無損失共振は f = f_k で発散するので拒否)。

多極で追加になる約束は 2 つ :

- **直流極限の一致** ε∞ + Σ Δε_k = εr を入力検証で要求する。これが崩れると
  静的容量が入力の εr と食い違うのに、実行は通って結果だけ静かにずれる。
  単極では Δε = εr − ε∞ と定義するので自動的に成り立つ。
- **各極は Δε_k > 0、f_k > 0 (Lorentz は g_k > 0 も)**。虚部の寄与は極ごとに
  Debye   b_k = −Δε_k q/(1+q²) ≤ 0、
  Lorentz b_k = −Δε_k qr/((1−q²)²+(qr)²) ≤ 0
  なので、和も必ず損失側に入る (符号を取り違えると増幅する媒質になる。
  Lorentz の分母の虚部を −jfg にすると e^{jωt} 規約で非因果になる)。
  どちらの極も f → 0 で Δε_k に戻るので、直流極限の約束は種類を問わない。

極はセル (`seg_t`) ではなく材料 (`diel_t`) が持ち、セルは索引 `didx` だけ
覚える。セル数は格子分割に比例するので、極の配列をセルに複製すると
規模に比例して無駄に増える。

同一周波数の極への分割は恒等式
Δε/(1+jf/f₀) = Δε_a/(1+jf/f₀) + Δε_b/(1+jf/f₀) (Δε = Δε_a + Δε_b)
なので、結果は bit 単位で変わらない。これが和の経路そのものの番人になる。

**番人**: `dielectric dC (pp)` (等電位面間の過剰容量ラダーは格子に依らず
厳密に (εr−1)ε0A/d になる : 実測残差 ~1e-6) / `dielectric epsr=1 noop` /
`dielectric G (tand)` (損失性平行平板の G = ωε0 εr tanδ A/d という
コード非依存の解析値。損失側を (εr−1) と取り違えるとここで 25% ずれる) /
`dielectric tand=0 noop` / `debye dY (3 freqs)` (ΔY(f) = jωε0(εr\*(f)−1)A/d
の 3 周波数 × 実部虚部。fr/100 と fr で ~2e-7、100fr は直列 L の準静的
補正が入り始めて ~5e-4) / `debye2 dY (5 freqs)` (2 極 = 単極では作れない
2 段の緩和。実測 1.3e-4) / `debye pole split` (同一周波数の極への分割が
bit 一致 = 和の経路の番人) / `lorentz dY (5 freqs)` (共振をまたぐ 5 点で
εr′ < 0 の 2 点を含む。分母の符号・q と r の取り違えはここで桁違いにずれる。
実測 3.5e-5) / `lorentz+debye dY` (種類の違う極の混在と逐次読み。
実測 4.3e-4) / `lorentz parser guard` (g ≤ 0・語の不足・強度の和の不一致の拒否) /
`drude dY (5 freqs)` (直流で G = σ_dc A/d、f = g で半分、εr′ < 1 の誘導性を含む :
実測 1.5e-3) / `sigma dY (5 freqs)` (G が周波数に依らない : 実測 2.1e-4) /
`sigma brick (epsr=1) G` (導電性なら εr = 1 でもセルを作る) /
`drude/sigma parser guard`

## (10) 遠方界の規格化とポインティング整合

遠方界は r E = −j(ωμ0/4π)[N − (N·r̂)r̂]、放射強度 U = |rE|²/(2η0)。
この規格化が正しいことは Prad = ∮U dΩ が回路側の入力電力
Pin = Re(Zin)/2 と一致する (低損失アンテナで効率 ≈ 1) ことで判定される。
係数を触るとパターン形状 (D) は変わらず**効率だけが静かに狂う**。

**番人**: `dipole ff efficiency` (実測 1.0004) / `short dipole D` (= 1.5 厳密) /
`monopole D = 2 x dipole` (鏡像遠方界と上半球積分)

## (11) 送信と受信は相反定理で結ばれている (平面波入射)

平面波入射 (`mna_rhs_planewave`) と遠方界 (`farfield.c`) は独立な実装だが、
離散化した系でも次の恒等式が**厳密に**成り立つ :

  l_eff = N_t = rE · 2λ/(-j η0)     (1 A 給電時の放射ベクトル)
  Voc   = -E0 (ê·l_eff)

符号 (−) はポート規約による : `mna_rhs_port` は n1 に +1 A を注入する一方、
Voc は v(n1) − v(n2) で測るため基準の向きが逆になる。**この符号は角度・偏波
によらず厳密に −1 倍**で、非対称構造の複数方向で確認済み (バグなら一定倍率に
ならない)。両者は位相規約 exp(+jk r̂·r)、sinc 積分、偏波ベクトル、鏡像規約を
共有しているので、片方だけ触ると必ずここが落ちる。

**番人**: `recip 30/45/p1` ほか 5 方向 × 偏波 (実測 ~3e-10) と
`recip 60/0/p1` (地板あり = 鏡像の送受一致)。振幅の絶対値は
`dipole pw leff` (= λ/π) と `loop pw |Voc|` (= kE0A) が別途アンカーする。

## (12) 過渡応答は exp(+jωt) 規約と等間隔掃引に依存する

`transient.c` の合成 y(t) = df[H(0)X(0) + 2ReΣH(f_k)X(f_k)e^{j2πf_k t}] は
コードベース全体の exp(+jωt) 規約 (inductor が +jωL) と一致していなければ
ならない。**純抵抗の判定 (S11 が実数) では共役の取り違えを検出できない**ので、
周波数依存のあるケースが必要になる。微小ループは Voc ∝ jω なので時間波形が
励振の微分になり、共役を取り違えると符号が反転する。

掃引は f_k = k·df (等間隔かつ DC の整数倍) でなければ時間軸が定義できない。
`tran_check()` がこれを検査し、対数掃引は明示的に拒否する。DC 項は掃引に
含まれないので、実数条件 Im H(0) = 0 のもとで下 2 点から線形補外する。

**番人**: `loop transient (d/dt)` (規約の一貫性) / `tdr R=...` 4 通り
(合成の線形性・スケール・符号) / `transient sweep guard` (掃引の検査)

## (13) 外側求積の次数は距離だけで決めてよい (内側が解析的に厳密だから)

面セル (リボン) と多角形セルの静的部は「内側の面積分は閉形式 + 外側だけ
Gauss 求積」という 2 段構成になっている。内側が厳密なので外側の被積分関数は
セルが離れるほど滑らかになり、必要な次数は**中心間距離 / セル寸法の比だけ**で
決まる。この性質を使って `ribbon_nq()` (partial.c) は 8 → 4 → 2 点、
`POLY_R7` は 7 点則 → 3 点則へ落としている。実測相対誤差 (基準は最高次) :

    d/h        1        2        5       10
  リボン 4 点  -2.7e-4  -8.4e-10 -7.7e-11 -2.9e-13
  リボン 2 点  -3.6e-3  -3.6e-05 -1.2e-05 -7.7e-07

**次数を落としてよいのは静的部だけ**で、自己項・隣接項 (比 <= 2.5) は最高次を
使う。ここを緩めると (4) の幅規格化と (6) の加法性が同時に劣化する。

不変条件 (2) との関係 : 遅延補正部は次数を変えていない。静的部の変更が放射
抵抗の打ち消しを汚さないことは、遅延あり面セル (平板ストリップ) で
Rin 942.8985 → 942.8986 Ω (相対 1.4e-7) と確認済み。(2) が守るのは中点近似の
ような O(1%) の系統差であって、この水準は問題にならない。

**番人**: `quad sheet L vs plate` (多角形経路とリボン経路の相互検証、許容
0.1% に対し実測 1e-5 レベル。両経路の求積を独立に粗くしているので、
片方が壊れるとここに出る) / `strip L (surface)` / `plate C (extrapolated)` /
`disk C (extrapolated)`

## (14) 非一様格子の幾何は格子座標の隣接中点 (双対区間) から導く

縁寄せ格子 (`grading = 1`) で plate のセル幅・中心・電荷セルは、格子座標
配列 xa[]/xb[] の隣接中点で決まる双対区間 [lo, hi] から導く :

  lo = (j == 0) ? x[0] : (x[j-1]+x[j])/2,  hi = (j == n) ? x[n] : (x[j]+x[j+1])/2

こうすると非一様でも面が重複なく張られ (Σwid = 全幅が厳密)、矩形格子の
DC 抵抗の厳密性 (不変条件 7 の plate 版) が保たれる。quad/disk はセルが
すべて格子点座標から導かれる構造なので `panel_node()` のパラメータ変換
(余弦 / 正弦) だけで整合する。等間隔時の座標式は従来と同一 (`i*h`) に
してあるので、キー省略時は完全後方互換。

**注意** : `node =` で格子点に接続する検証ケースは、縁寄せ後の座標に
ノードを置くこと。座標が食い違うと nodetol マージが外れて**接続が静かに
切れ**、quad 1 スクエアの DC が +46% ずれる (実際に踏んだ。
quad_square_graded.peec は余弦位置を 16 桁で記載している)。

**番人**: `graded quad Rin (DC)` / `graded quad L vs plate` (多角形経路と
矩形リボン経路が同一の非一様格子を作ること) / `graded thick plate R`
(体積セル併用) / `graded plate C (8x8)` / `graded8 beats uniform16`
(縁寄せの存在意義 : 未知数 1/4 で等間隔 16x16 を上回る)

## (15) 圧縮経路は密経路と同じ要素評価を共有する (compression = 1)

H 行列圧縮 (hmatrix.c) が壊れても実行は通り、Zin が数 % 〜数十 % 静かに
ずれる。守るべき構造は 3 つ。

- **要素評価は `lp_entry()` (partial.c) の 1 箇所だけ**。`lp_fill()` も
  ACA も近傍ブロックもこれを呼ぶので、密経路と圧縮経路の要素は構造的に
  ビット一致する。本体を二重に持つと必ずずれる (実際に踏んだ : 求積次数が
  引数順序に依存する (13) ため、上三角ミラーと独立評価で下三角が ~1e-5
  ずれた。`lp_entry()` は i <= j に正規化して吸収している)。
- **ACA は可約ブロックで再開が要る**。Lp の要素は方向余弦 (t_i・t_j) を
  含み、直交セルどうしで**厳密に 0** になる。格子状の面導体では x 向きと
  y 向きの群が混在し、素朴な部分ピボット ACA は片方の群だけ見て「収束」する
  (ブロック誤差 0.76 がランクを 8 → 23 に上げても不変、が症状)。
  各行が u_l に現れた最大値 urep[] を記録し、収束したように見えたときに
  未出現の行から再開する (aca_block の HM_PROBE)。
- **matvec の並列単位は葉クラスタ** ([0, n) を重複なく分割する)。ブロックの
  行区間は木の階層をまたいで重なるので、行クラスタ単位で並列化すると
  複数スレッドが y の同じ要素を read-modify-write して寄与を落とす
  (実際に踏んだ : 相対誤差 ~0.5 が実行ごとに変わる)。hmat_build() が
  葉の敷き詰めを自己検査して崩れていれば失敗させる。

前処理 (precond.c) は葉対角ブロック + 疎回路部だけから組むので近似だが、
**GMRES の収束判定 (相対 1e-10) を通った解の精度は前処理に依存しない**。
前処理の設計変更は反復数を変えるだけで結果を変えない (変わったら操作側
(mna_apply / hmat_matvec) のバグ)。

## (16) 圧縮の容量性 PEEC は電荷を陽な未知数にする (P^-1 を作らない)

節点容量 C = P^-1 は密な逆行列で、O(ncell^2) のメモリと O(ncell^3) の時間を
要する。圧縮経路ではこれを作らず、電荷 q を未知数に足して

  KCL 行   : ... + jw q_i = 0                     (mna.c : stamp(mi, offQ+i, +jw))
  電荷行 i : sum_j P(i,j) q_j - v_i = 0           (stamp(offQ+i, mi, -1))

と組む。電荷行から q = P^-1 v なので KCL には jw (C v)_i が入り、**密経路と
厳密に同じ系**になる (基準ノードは v = 0 なので列が落ちるだけ)。

- 符号を取り違えると (KCL を -jw q にする、電荷行を v - Pq にする) 容量が
  逆符号に効き、Xin の符号が反転する。
- P の要素は `pot_entry()` (potential.c) の 1 箇所だけで評価する。密経路の
  集約 (ig を作ってからセルに足す) と同じ式・同じ鏡像規約で、サブセル対の
  順序も上三角に正規化してあるので両経路はビット一致する。
- 電荷セルの構成 (`pot_cells`) は幾何のみなので密・圧縮で共通。圧縮では
  `mna_numbering` がこれを呼んで ncell を確定させる (未知数の個数に要る)。
- 総容量 Ctotal = 1^T P^-1 1 は逆行列を要するので圧縮経路では出さない。

**近似が入らない規模 (全ブロックが近傍) では両経路の Zin がビット単位で
一致する**ことが、この定式化が厳密に等価であることの最も強い判定になる。

**番人**: `compress wire L` (解析解、木が分割される ndiv=200) /
`compress plate Rin` / `compress plate L` (直交セル混在の密経路との相互検証、
ACA 再開の番人) / `compress thread invar.` (葉並列の競合検出) /
`compress cap Rin` / `compress cap L` (容量性の圧縮 = P 側 H 行列と 2 ブロック
前処理) / `compress cap exact` (無近似規模での厳密一致 = 電荷定式化そのもの)

## (17) 前処理の Schur 補元は疎に持ち、厳密に分解する (compression = 1)

Schur 補元 S = S11 - sum_b B_b D_b^-1 C_b は回路未知数どうしの行列で、葉 r が
触れる回路未知数は幾何的に局所的なので、S は「葉ごとのクリークの重ね合わせ」
= 局所パターンになる。1 行あたりの非ゼロ数は規模によらず ~36 に飽和する
(12x12 の板で 27.6、20x20 で 35.4、28x28 で 36.3、40x40 で 35.8)。

- **疎にするのは格納と分解だけで、前処理そのものは変えない。** 分解は近似
  (ILU 等) ではなく厳密な LU なので、GMRES の反復数も収束先も密のときと
  変わらない。実測でも反復数は完全に一致し、Zin はバイト単位で一致する。
  ここが崩れたら「疎にしただけ」ではなくなっているということ。
- 順序付けは最小次数 (`mindeg_order`)。充填は nnz の 1.3〜1.6 倍で、密比では
  規模が大きいほど有利になる (9.6x -> 16x -> 29x)。RCM は 2.8〜4.9 倍で
  伸びも速いので使わない。順序付けが打ち切られたら自然順に落ちるだけで
  結果は変わらない。
- **消去グラフの重複辺を必ず潰す**。A + A^T を作るとき (i,j) と (j,i) が
  両方あると同じ辺を 2 回積み、次数が真の値の 2 倍まで膨らんで次数バケット
  `head[deg]` (長さ n+1) を突き抜ける。実際に踏んだ : n=18 の Schur で
  `adj[0].len = 34` となり隣の確保領域 (MNA の三つ組) を壊して、3 周波数目
  だけ結果が狂った。ASan では再現しなかった。
- MNA には**対角が構造的にゼロの行**がある (電圧源の枝電流 i_V は
  v_a - v_b = V なので (i_V,i_V) を持たない)。充填を抑えるための閾値ピボット
  は対角を優先するが、対角がパターンに無い / 小さいときは非対角へ落ちること。

**番人**: `compress schur Rin` / `compress schur L` (集中定数の枝で i_L と i_V
を Schur に入れ、非対角ピボットの経路を通す) / `compress cap exact`
(n1 = 18 のほぼ完全グラフ = 重複辺による突き抜けが出る規模)

## (18) 近傍界は解と同じ規約・同じ求積点で評価する (nearfield)

近傍界 (nearfield.c) は後処理なので壊れても Zin は変わらない。代わりに
`near.csv` だけが静かに狂う。守るべき構造は 5 つ。

- **位相規約はコードベース全体と同じ** exp(+j omega t) / g(R) = exp(-jkR)/R。
  勾配は grad_r g = -(1 + jkR) exp(-jkR)/R^3 (r - r') で、これから
  E = -j omega A - grad phi、H = (1/mu0) rot A を組む。指数の符号を
  取り違えると遠方で farfield.c の漸近形と一致しなくなる。
- **求積点は cell_qpts() (polygon.c) の 1 箇所から取る**。細線 / リボン /
  多角形の振り分けを近傍界側にもう一度書くと、セル形状を足したときに
  片方だけ直し忘れる。電流セルの幅規格化は不変条件 (4) と同じ
  ((1/wid) x 面積分 = 線積分)。
- **電荷はセル内一様密度**。サブセルの重みは電位係数 `pot_entry()` と同じ
  len_h / carea[i] にする。ここを面積で割ると面セルで規格化が二重になる。
- **鏡像規約は (8) と同一** (幾何鏡像 + 電流 -I / 電荷 -q)。符号が正しければ
  地板面上で接線 E と法線 H が機械精度で 0 になる。取り違えると打ち消しでは
  なく 2 倍になるので、比は O(1) になって即座に出る。
- **retardation = 0 なら k = 0 で評価する**。部分要素が静的なのに場だけ遅延
  させると、解が持っていないはずの放射項が場に現れる。
- **平面波の全界 (nearpw.csv) の入射界は右辺と同じ `pw_waves()` (mna.c) から
  組む**。到来方向・偏波・地板での反射 (水平成分反転・垂直成分保存、面上で
  位相一致) を近傍界側で書き直すと、起電力と入射界の規約がずれても実行は
  通る。入射界は物理的な平面波なので **retardation に依らず k = omega/c**
  (右辺の起電力も同じ k)。散乱界だけが上の k の規約に従う。
  H_inc = -(1/eta0) r^ x E_inc (伝搬方向は -r^)。

観測点ごとの評価は互いに独立 (出力配列の別要素) なのでリダクションが無く、
OpenMP でもスレッド数によらずビット一致する。

セル上の積分はセルあたり数点の求積なので、観測点をセル寸法より近くに置くと
求積誤差が残る。検証ケースはこれを満たす配置にしてある (正方ループは
セル長 0.01 m に対し最短距離 0.05 m)。

**番人**: `near loop Hz (z=0.05/0.10/0.20)` (有限直線 4 本の Biot-Savart 和
という閉形式、実測 7e-6) / `near disk Ez (z=0.1/0.5)` (総電荷 Q = I/(j omega)
は電荷保存で厳密、導体円板の平衡分布から E_z = Q/(4 pi eps0 (z^2+a^2))) /
`near vs far (theta=90/45)` (r = 24 lambda で |E| = |rE|/r : 漸近形と全項
数値求積の相互検証) / `near gp boundary` (鏡像の符号) /
`near thread invariance` /
`pw standing Ey / Hx` (地板上の定在波 E_y = 2j E0 sin kz, H_x = 2(E0/eta0) cos kz
の厳密解 : 反射の符号と位相、H の向き) / `loop shield |Htot/Hinc|` (閉ループの
中心で 1 - j omega mu0 G A/(R + j omega L) : 散乱界の符号 = レンツの法則) /
`pw compensation` (補償定理 F_B = F_A,pw - I_L F_A,port : 平面波経路の誘起電流・

## (19) 混合モード S は単端 S の直交な組替えで作る (mixedmode)

混合モード S (output.c の `output_mixed()`) は後処理なので壊れても Zin や
`peec.sNp` は変わらない。`mixed.csv` だけが静かに狂う。守るべき約束は 3 つ。

- **組替え行列 M は直交**。差動対 k = (p_k, n_k) について
  a_dk = (a_pk − a_nk)/√2、a_ck = (a_pk + a_nk)/√2、対に入らないポートは
  そのまま (係数 1)。S_mm = M S Mᵀ (M⁻¹ = Mᵀ)。√2 を落とすと |S| が 2 倍に
  なり受動性が壊れ、符号を落とすと d と c が入れ替わる。直交なので
  Σ|S_mm|² = Σ|S|² (フロベニウスノルム保存) が組替えの番人になる。
- **基準抵抗は差動 2·z0、同相 z0/2**。電力波の組替えがこの基準と整合するのは
  対の 2 ポートの z0 が等しいときだけなので、入力検査で強制する (異なる z0 を
  黙って通すと、どちらの基準でも正しくない値が出る)。
- **並びは d1..dP, c1..cP, 単端 (元の番号順)**。ラベル (`d1` / `c2` / `s3`) は
  この並びと 1 対 1。Sdd21 は S(d2,d1) (行 = 応答、列 = 励振)。

**番人**: `mixed-mode (2 pairs)` / `mixed-mode (pair + s3/s4)` (ABCD 行列から
作った単端 S を Bockelman-Eisenstadt の定義式で組み替えた全成分との比較 :

## (20) 散乱遠方界は送信と同じ放射ベクトルで作る (planewave + farfield)

平面波の散乱界 (`farpw.csv`、farfield.c の `output_farpw()`) は後処理なので
壊れても Zin・Voc は変わらない。`farpw.csv` と peec.log の断面積だけが静かに
狂う。守るべき約束は 3 つ。

- **放射ベクトルは `ff_nvec()` の 1 箇所**。port #1 励振 (`far.csv`) と平面波の
  散乱 (`farpw.csv`) は電流配列 (`segi` / `segipw`) を差し替えるだけで、
  sinc・位相 exp(+jk r̂·r)・鏡像規約 (8) を共有する。散乱側だけ式を書き直すと
  相反 (11) と補償定理の整合が崩れる。`ff_nvec()` へ切り出したとき far.csv は
  main とバイト一致することを確認済み。
- **光学定理の符号は exp(+jωt) 規約で決まる**。
  σ_e = −(4π/k) Im[ê·rE_s(d)/E₀] (d = 伝搬方向 = −到来方向)。Bohren-Huffman の
  (4π/k) Im[...] は e^{−iωt} 規約なので、複素共役を取ると符号が反転する。
  符号を取り違えると σ_e が負になる。
- **エネルギー保存は retardation = 1 が前提**。離散系では前方散乱振幅と回路が
  入射波から受け取る電力 ½ Re Σ_m emf_m conj(I_m) が恒等的に等しい
  (起電力と放射ベクトルが同じ区間積分を共有するため)。だから
  σ_e = σ_s + σ_a は回路に放射抵抗 (遅延) が入っているときだけ成り立つ。
  retardation = 0 では σ_e は吸収分 σ_a だけを返す (実際に踏んだ : 短絡
  ループで σ_e がちょうど σ_s の分だけ 1.4% 小さく出た)。ログに注意を出す。

地板があるときは入射が 2 波 (直接 + 反射) になって前方方向が 1 つに
決まらないので、σ_e は出さない (RCS と σ_s は上半球で出す)。

**番人**: `loop RCS sigma(y^)` / `loop sigma_scat` / `loop sigma_ext (optical)`
(短絡した微小ループ : ファラデー + オーム + 磁気双極子の放射。L は Grover 式、

## (21) 伝送線路は進行波の関係で組む (tline)

伝送線路 (mna.c の `tline` スタンプ) は 2 つの端子対の間の TEM 線路で、
端子電流 i1 (n1 → 線路 → n2)、i2 (n3 → 線路 → n4) を未知数に足し

  v1 − Z0 i1 − T (v2 + Z0 i2) = 0
  v2 − Z0 i2 − T (v1 + Z0 i1) = 0,   T = a e^{−jω td}

の 2 行を組む (入射波 a = (v + Z0 i)/2、反射波 b = (v − Z0 i)/2 に対して
b1 = T a2、b2 = T a1 : Branin の方法の周波数領域版)。守るべき約束は 4 つ。

- **Z / Y 行列の形にしない**。Z11 = −jZ0 cot θ、Z12 = −jZ0 csc θ (Y も同様) は
  θ = ω td = nπ で発散し、半波長・全波長の点で行列が壊れる。進行波の形は
  対角が常に −Z0 で、どの θ でも係数が有界。
- **T の偏角 −ω td が遅延**。exp(+jωt) 規約では e^{−jω td} が遅れなので、
  符号を取り違えると反射が前進し (TDR で y(t) = Γx(t + 2td))、S21 の位相が
  逆に回る。λ/4 変換 (Zin = Z0²/ZL) のように tan の偶関数性で符号が消える
  判定だけでは検出できない (実際にこの判定だけは符号反転でも通った)。
- **端子対ごとに電流は行き帰りで等しい**。同相の経路を作らないので、
  容量性 PEEC の総電荷の保存 (不変条件 3) を壊さずに浮いた端子対で構造に
  繋げる (線路の先の半波長ダイポール)。
- **損失は無ひずみ線路**。a = 10^(−dB/20) を周波数に依らず掛けるのは
  R/L = G/C の Heaviside 線路に相当し、そのとき Z0 は実数のまま。√f の
  表皮損失や分散は持たない (README の制限)。

未知数ブロック (offT, 1 本 2 個) は offS より前 = 回路側なので、圧縮経路
(compression = 1) では前処理の Schur 補元に入る。対角が −Z0 で構造的に
ゼロではないので、閾値ピボットの非対角落ち (不変条件 17) にも頼らない。

**番人**: `tline Zin (lossless)` / `tline Zin (2 dB loss)` (教科書の tan / tanh の
式との代数的一致、実測 7e-17 / 1e-10) / `tline matched S (3 dB)` (位相の向き) /
`tline TDR delay` (遅延の符号、前進させると 0.49 ずれる) / `tline-fed dipole`
(容量性 + 遅延の PEEC との接続、実測 1.7e-10) / `tline compress = dense`
(圧縮経路の回路側、ビット一致) / `tline parser guard`

## (22) 励振の重みはポート解の重ね合わせ (excitation)

`excitation` があると遠方界・近傍界はポート解 (ポート j に 1 A、他は開放) を
重み w_j = 振幅 e^{j 位相} で重ね合わせた電流・電荷で評価する。線形性から
全ポートに電流 w_j を同時に注入した解そのもので近似は無い。守るべき約束は 3 つ。

- **電流と電荷の両方を重ね合わせる** (output.c の `exc_mix()` を `segi` と
  `cellq` の両方に通す)。電流だけ重ね合わせると近傍界の −∇φ が port #1 の
  電荷のまま残り、E が静かに狂う (遠方界は電流だけなので気付けない)。
- **入力電力は相互結合込みの Pin = ½Re(wᴴZw)** (`exc_pin()`、
  Z_ij = `zmat[ZIDX(ifreq, i, j)]` = V_i/I_j)。対角だけ (ΣRe Z_jj|w_j|²/2) に
  すると、逆相と同相で相互抵抗 R21 の寄与が逆符号に効く分だけ効率が狂う
  (λ/2 間隔の半波長ダイポール対で ±15%)。
- **行が無ければ base をそのまま返す**。port #1 に 1 A の従来出力とビット一致
  (`excitation = 1 1` を書いても一致)。

`dist.csv` は従来どおりポートごとの分布 (重ね合わせない)。平面波 (`farpw.csv` /
`nearpw.csv`) は励振と無関係。

**番人**: `array antiphase null` (鏡映対称 + 反対称励振で ±y の遠方界が 0 :
実測 7e-16) / `array near Ez (x=0)` (x = 0 面の E_z = 0 : 電荷の重ね合わせの
番人、実測 2e-15) / `array Pin = Re(wHZw)/2` (S から組んだ Z との一致) /
`array ff eff (antiphase)` / `array ff eff (in-phase)` (相互結合の符号) /
`excitation superposition` (位相の規約) / `excitation default` (後方互換) /
`excitation parser guard`

## 並列化

`lp_fill` / `pot_fill` / 近傍界の観測点ループは OpenMP 並列。並列ループ内で
共有配列に `+=` しない (`pot_fill` は積分結果を一時配列に出してから直列で
集約している)。
スレッド数によらず出力がビット一致することを必ず確認する。
